# 音読の文を毎日5つ足す手順（直問！）

公式LINEで「音読」と送ると、1日1文ずつ新しい文が届く。その在庫を毎日5文ずつ増やす。

## 手順（この順番を守る）
1. `python3 ondoku/tools/catalog.py` を実行して、**全部のカテゴリの数と、これまでの全部の文**を読む。読まずに作らない。
2. 作るカテゴリを決める：**数が少ないカテゴリから順に5つ**（同じカテゴリは1日2文まで）。
3. 5文を作って `new.json` に書く（形は下）。
4. `python3 ondoku/tools/add.py new.json` を実行する。「はねた」が出たら、理由を読んで作り直し、足りない分だけもう一度 add.py にかける（合計5文になるまで）。
5. 足した5文を、もう一度自分で読み直す（英語が自然か／日本語がかたまりごとに合っているか／カテゴリが合っているか）。おかしければ sentences.json から消して作り直す。
6. git で ondoku/sentences.json と ondoku/*.m4a を commit して push する。

## 文の決まり
- TOEIC の Part 5〜7 に出てくる仕事の英語（お知らせ・メール・社内の連絡・店や会社の案内など）。話題は毎日ばらす（人事・購買・出張・設備・イベント・外食・製造・IT・財務・不動産・健康・顧客対応）。
- 1文 12〜24 語。かたまり（意味のまとまり）は 3〜5 個。かたまりの切れ目は、声に出して読むときに自然に間があく場所（直問！の「前から読む」の区切り）。
- 数字は英語のつづりで書く（twenty, March first など）。記号（$, %）は使わない。
- 人名・会社名・地名は、これまでの文に出ていない新しいものにする（add.py が調べる）。
- これまでの文と言い回しが似すぎないこと（add.py が調べる）。同じ構文でも、動詞・話題・場面を変える。
- 日本語は「前からの意味」。かたまりごとに、英語の順番のまま短く訳す（返り読みしない）。
- 質問（Would / Could … ?）は C08 だけ。

## 文の決まり（2026-11-03 から足す。品質基準 v3）
- この文は「完成した英文を前から理解して、声に出す」ための教材。**主語の核・述語・修飾のまとまり**が、かたまりの区切りとそろうようにする（区切りは構造を見る足場）。修飾が長い主語も入れる（例：The assistants in the sales office｜have carefully reviewed｜the revised proposal.）。
- 語彙は1語ではなく**組み合わせ**で入れる（動詞＋目的語：address a problem／respond to an inquiry、形容詞＋前置詞：responsible for、名詞＋前置詞：demand for）。
- 場面を会議・部署・予算にかたよらせない。店・旅行・お知らせ・サービス・施設・地域の行事なども使う。
- まれな語・辞書にない形・不自然な連語を使わない。作ったら、節ごとに主語と述語がそろっているかを確かめる。
- 日本語の訳に「必ず」「これだけ」のような言い切りの説明を入れない（訳だけを書く）。

## new.json の形
```json
[
  {"cat": "C10", "chunks": ["Not until the inspection was finished|点検が終わってはじめて", "did the factory resume production|工場は生産を再開した"]}
]
```
（"英語のかたまり|日本語" をかたまりの数だけ並べる）

## カテゴリ
ondoku/tools/categories.json にある13種類（C01〜C13）。名前・説明・例文はそこを見る。
