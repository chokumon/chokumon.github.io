分詞構文
「国語で読む」だけでいい

英文の前や後ろに、カンマで区切られた -ing・-ed のカタマリがくっついていることがあります。

学校では「分詞構文」「理由・条件・譲歩・付帯状況…」と習いますが、名前も分類も覚えなくてOK。カタマリはメインの文に「状況」を足しているだけです。

読み方並べて国語でつなぐ
-ing主語が 〜している
-ed主語が 〜される
STEP 1

「状況」を足しているだけ

文の前の -ing のカタマリは、国語で読む

文の前にある、カンマで区切った -ing のカタマリは、メインの文に「状況」を足しているだけです。

Walking to the station,状況のカタマリ（駅まで歩いている）
I met an old friend.メインの文（私は昔の友だちに会った）

読み方はこの順

  1. カンマのあとのメインの文（主語＋動詞）を先に見つける
  2. -ing のカタマリは、メインの文の主語が〜していると読む
  3. 2つを並べて、国語として一番自然につながる日本語を自分で作る
Walking to the station, I met an old friend.駅まで歩いていて、昔の友だちに会った。I was walking …
Feeling sick, Mr. Ito left work early.気分が悪かったので、伊藤さんは早退した。Mr. Ito was feeling sick.
Using the new app, customers can order in advance.新しいアプリを使えば、客は前もって注文できる。Customers use the new app.
日本語のつなぎ方は、メインの文の中身で自然に決まります。決まった訳し方の表はありません。
日本語を作ってみて、声に出して自然に聞こえれば正解。1つの文に自然な日本語が2つ以上あることもふつうです。

▶ 似た形でくらべる

Checking the list, she found a mistake.リストを確認していて、彼女はまちがいを見つけた（カンマあり → 状況。彼女が確認している）
Checking the list is her job.リストを確認することが彼女の仕事だ（カンマなし・is の主語 → 「〜すること」）

例題 1

( Using ／ Uses ) the new app, customers can order meals in advance.
答えと解説を見る

答え：Using the new app, customers can order meals in advance.

メインの文は customers can order。Uses だと文の動詞が2つになる。客がアプリを「使っている」→ Using

訳：新しいアプリを使えば、客は前もって食事を注文できる。

例題 2

( Knowing ／ Knows ) the area well, Mr. Okafor offered to guide the visitors.
答えと解説を見る

答え：Knowing the area well, Mr. Okafor offered to guide the visitors.

メインの文は Mr. Okafor offered。オカフォーさんが地域をよく「知っている」→ Knowing

訳：その地域をよく知っていたので、オカフォーさんは訪問者の案内を申し出た。

STEP 1　練習問題

状況のカタマリに [　] をつけ、メインの文の動詞に下線を引こう。

1.　Checking in at the front desk, the guests were given a welcome drink.

2.　Hearing the fire alarm, everyone left the building quickly.

3.　Riding a bicycle to work, Ms. Nair gets some exercise every day.

4.　Hoping to attract more tourists, the town built a new visitor centre.
