直問！のもとは「直読直解（前から読んで、前から分かる）」と「問い読み（分からないところで問いを立てる）」の2つです。

速く読める。
「時間が足りない」が減る。

日本語の順に直そうとすると、目が文の後ろから前へ何度も戻ります。前から読めば、文を1回通るだけで意味が取れます。

返り読み前から 41I went to the store店に行った 32to buy some milk牛乳を買いに 23because we had noneなかったから 14at home.家に

返り読みは下から上へ戻って訳します。前からなら上から下へ1回。長い文ほど差が開きます。

リスニングも、
聞いた順に分かる。

音声は流れて消えるので、戻って読み直せません。前から理解するクセがつくと、聞こえた順にそのまま意味が入ってきます。

「どのファイル？」と問いを持って待つと、すぐ後ろで答えが聞こえてきます。読むときと同じ頭の使い方です。

英語を、
英語の順番のまま分かる。

英語は、起きた順・目に入る順に言葉が並びます。日本語に並べ替えなくても、その順番で場面を思い浮かべれば意味が分かります。

映画のカメラのように、ドア → 猫 → 寝ている → ベッド。これが英語を英語のまま分かる状態です。

むずかしい文法用語は、
覚えなくていい。

文のしくみを用語で覚えるかわりに、「何を？」「だれが？」「いつ？」と問うだけ。中学生にも分かる言葉で、同じことが分かります。

This is the book I read last week.

用語だと目的格の関係代名詞 which が省略されている 問いだと「読んだ、何を？」→ the book（この本）

「これは本。先週読んだ（何を？ → その本を）」。用語を知らなくても、問い1つで文がつながります。

前から読む。空欄で問う。
後ろで答えを拾う。

空欄の近くの言葉だけで選ぶと、ワナにかかります。直問！は英文を返り読みせず頭から読み、空欄に問いを持ったまま先へ進みます。

  1. 1前から読む英語の語順のまま、かたまりごとに意味を取ります。
  2. 2空欄で問いを立てる「いつの話？」「何が？」「する側？される側？」など、その空欄に合う問いを1つ持ちます。
  3. 3後ろで答えを拾う読み進めると、問いの答えが文の中に出てきます。それに合う選択肢を選びます。
